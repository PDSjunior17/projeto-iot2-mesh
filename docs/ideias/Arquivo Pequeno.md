2. A interface do usuário cria um aviso para alertar a rede que uma mensagem será enviada, o cabeçalho é: id_origem/id_destino/n/flag_recebimento/código_aleatório_uníco_da_mensagem/ACK
3. A interface do usuário conecta via blueethoh a um nó da rede e informa que vai enviar um aviso e passa o mesmo
4. O nó envia o aviso em um tempo aleatório dentre um intervalo (para evitar que o aviso colida com outro se algum outro nó tiver usando o canal ao mesmo tempo) para os demais nó da rede em um canal específico (é sempre utilizado o mesmo canal para enviar avisos), cada nó que receber aquele aviso vai retrasmitir ele então vai trocar para o primeiro canal de mensagem (haverá canais especificamente para o envio e recebimento de mensagens, sendo que existe um limite para o número de blocos que é enviado por canal e o nó sabe disso, assim que atinge esse limite ele automáticamente muda para o póximo canal para receber os póximos blocos até atingir o valor de n. As mensagens terão a hora e data que forma enviadas criptografadas como a primeira informação do bloco e no final junto com o número do bloco que é informação legível terá o código_aleatório_uníco_da_mensagem seguido do ACK(acho que é CRC)). O nó retransmite aquele aviso e aquela mensagem um número M-1 de vezes(talvez adicionar um número que representa quantas vezes aquela mensagem foi transmitida);
5. Depois de receber toda a mensagem(as mensagens tem o conteúdo/número do bloco) ele verifica usando o algoritmo de cálculo de erro e o número ACK(Acho que é CRC) para saber se algum bloco sofreu interferência durante o envio, caso tenha sofrido o nó pede a rede que envie aquele bloco novamente;
6. Assim que receber toda a mensagem e confirmar que ela está certa, o nó monta a mensagem em um arquivo único salvando-o no cartão de memória, ele verifica se o id_destino está conectado a ele no momento, se estiver ele envia o arquivo para ele, se não ele compartilha o arquivo baixado com os demais nós utilizando uma distância específica (os nós estaram espacialmente organizados sendo que terá três mais pertos, em que eles irão utilizar a distância longa de comunicação para comunicar  avisos e redundância de dados com nós distante e irão usar a distância curta para enviar mensagens entre eles criando uma redundância dos arquivos armazenados no cartão sd)
7. Quando um nó identificar que o id_destino está conectado a ele, o nó envia a mensagem para ele informando o destinatário e a mensagem e o dispositivo avisa se conseguiu receber a mensagem e descriptogrfar corretamente, caso tenha conseguido o nó envia um aviso para os demais nós da rede avisando que a mensagem foi entregue ao destinatário, com o cabeçalho id_origem/id_destino/n/flag_recebimento(valor 1 indicando que foi recebido peo destinatário)/código_aleatório_uníco_da_mensagem/ACK
8. Os nós que receberem esse aviso irão adicionar 1 (que siginfica recebido) na tabela interna que está salva no cartão, tabela essa que associa cada mensagem a se  o destinatário daquela mensagem a recebeu ou não. Toda vez que um dispositivo se conecta a um nó ele verifica se tem alguma mensagem não recebida para aquele usuário, se tiver ele entrega e comunica a rede através do aviso de recebimento;
9.  Quando a rede estiver ociosa vai rodar a cada x minutos uma rotina para os nós compartilharem os seus arquivos entre si para gerar redundância na rede;
10.
